# Changelog

## v0.3

### Added
- Logical negation with `not()`.
- Support for single-argument mathematical expressions: `sin()`, `cos()`, `sqrt()`, `abs()`, `flr()`, and `cel()`.

### Improved
- Expression parsing now handles nested function calls and quoted strings more reliably.
- Updated value conversion and expression evaluation.
- Adjusted control-flow parsing and file operations.
- Updated system-command execution.

### Changed
- Arithmetic expressions no longer enforce a universal two-argument limit.
